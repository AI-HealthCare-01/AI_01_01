# 활동로그 결정사항

## 역할
- 활동로그는 사용자가 "그날 무엇을 했는지"를 하루 단위로 돌아보는 기능이다.
- 체크인, 챌린지, CBT, 일기, 설문 수행 여부를 한곳에서 확인할 수 있다.

## 포함
- 체크인 작성 여부
- 챌린지 수행 여부/개수
- CBT 활동 여부/세션 수
- 일기 작성 여부/개수
- 설문 수행 여부

## 제외
- 자유일기 작성 기능
- 일기 본문 전체 기본 노출
- 원천 이벤트 로그를 그대로 나열하는 운영 로그형 화면

## 연동
- 마이페이지: 활동로그 진입점과 최근 활동 요약
- 요약리포트: 기간 내 활동 빈도/수행일 수만 사용
- 대시보드: 직접 연결보다 최근 활동 요약 수준으로 연결
