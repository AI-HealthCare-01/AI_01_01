# 대시보드 Blueprint

목표:
- 사용자가 자신의 **상태 변화**와 **활동 기록**을 한눈에 이해할 수 있게 한다.
- 상태 대시보드와 활동 대시보드를 분리해 목적을 명확하게 한다.
- 상태 대시보드는 우울/불안/불면 지표를 보여주고, 활동 대시보드는 체크인/챌린지/CBT 기록을 보여준다.

버전: v1.0
작성일: 2026-03-01

## 구성
- `00_overview/` : 핵심 결정사항, 포함/제외, 근거 자료
- `01_product/` : IA, UX 규칙, 사용자 카피
- `02_domain/` : 데이터 계약, 파생 지표 정의, 결측 처리
- `03_backend/` : API 계약(OpenAPI snippet)
- `04_frontend/` : 화면 구성, 그래프 규칙, 컴포넌트
- `05_states/` : loading/empty/error 상태, 데이터 충분도 배너
- `06_implementation/` : phased todo, acceptance criteria
- `codex_prompts/` : Codex 시작 프롬프트

## 핵심 원칙
1. 상태 대시보드:
   - 최근 7일 버전과 최근 4주 평균 버전을 둘 다 제공
   - 우울/불안/불면은 **각각 별도 그래프**로 표시
   - 세 그래프는 **한 화면, 한 도화지 안**에 함께 배치한다
   - 박스/카드 분리 없이 세로 정렬한 3개 그래프로 구성
2. 결측 처리:
   - 7일 버전: 기록 없는 날은 비워두고, 기록 있는 날짜끼리 연결
   - 4주 평균 버전: 해당 주에 하루라도 기록이 있으면 주평균 생성, 주 전체 결측이면 비움
3. 활동 대시보드:
   - '출석률' 대신 '체크인한 날', '기록한 날' 표현 사용
   - 월간 캘린더형 체크인 표시
   - CBT는 최근 7일 세션 수와 마지막 활동일
   - 챌린지는 진행 중/최근 7일 수행일 수/완료율을 중심으로 표시
