# 사용자 플로우

## A. 회원가입
- 입력:
  - 닉네임
  - 이메일
  - 비밀번호
  - 비밀번호 확인
  - 필수 동의
- 완료 후:
  - '이메일 확인 메일을 보냈어요' 안내
  - 재발송 버튼(쿨다운 적용)

## B. 이메일 확인
- 메일의 링크 클릭
- Firebase action link 처리
- 성공 시:
  - 이메일 확인 완료
  - 로그인 페이지 또는 앱으로 복귀
- 실패/만료 시:
  - 재발송 유도

## C. 첫 로그인
- account_status = active_onboarding_required 이면 온보딩으로 강제 이동

## D. 온보딩
1. 민감정보/개인화 동의
2. 출생년도 입력
3. 성별(선택)
4. 초기 진단척도 1회
5. 완료 후 홈 진입

## E. 비밀번호 재설정
- 이메일 입력
- reset email 발송
- 링크 클릭 후 새 비밀번호 설정
- 성공 후 로그인 유도

## F. 이메일 변경(후순위지만 연동 필요)
- 최근 재인증
- 새 이메일 입력
- 새 이메일 확인 메일 발송
- 확인 후 반영
