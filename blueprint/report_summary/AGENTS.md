# Codex 작업 규칙 (요약 리포트)

- 이 폴더는 `blueprint/report_summary/` 기준으로 설계되어 있다.
- 구현 시 원칙:
  1) 의료행위(진단/치료/처방)처럼 보이는 문구 금지. "참고", "자기기록 기반"을 명시.
  2) 위험 플래그는 **구조화된 신호만** 표시. LLM 추론값(핵심믿음/인지왜곡 카운트 등) 기본 표시 금지.
  3) 사용자 이름/닉네임은 리포트 헤더에 포함하지 않는다.
  4) 기간 내 데이터가 부족하면 "관찰 밀도(데이터 신뢰도)"를 자동 표시한다.
  5) PDF/이미지 내보내기는 서버 측 렌더링(권장: HTML->PDF/PNG)으로 구현한다.
- 코드 작성 시:
  - 타입/스키마 우선: `02_domain/data_contracts.json` 준수
  - 모든 API는 인증 필요(사용자 본인만 접근)
  - 내보내기 파일은 짧은 만료(예: 10분) 다운로드 URL 또는 직접 스트리밍
