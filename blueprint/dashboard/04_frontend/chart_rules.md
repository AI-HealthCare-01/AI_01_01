# 차트 규칙

## 상태 차트(공통)
- 우울/불안/불면 3개를 한 그래프에 겹치지 않는다
- 하나의 대시보드 화면 안에 3개를 세로로 배치한다
- 각 지표는 라인 차트 사용
- 점을 표시해 관측이 있었던 날/주를 알 수 있게 한다
- 결측값은 점이 없고, x축 간격은 유지한다

## 7일 모드
- x축: 최근 7일 날짜
- null 날짜는 점 없음
- 양 옆 관측점이 있으면 선 연결 허용

## 4주 평균 모드
- x축: 최근 4개 주
- 주 전체 결측이면 점 없음
- 주평균이 있는 주끼리는 선 연결

## 시각적 주의
- 카드/박스에 강하게 분리하지 않는다
- 하나의 canvas 위에 3개 그래프를 두되, 제목/축/여백으로 구분한다
- 색은 지표별 고정(예: 우울/불안/불면)
- 색약 접근성 고려
