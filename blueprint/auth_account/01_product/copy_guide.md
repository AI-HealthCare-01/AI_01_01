# UX 카피 가이드

## 회원가입
- 제목: 계정 만들기
- 보조문구: 이메일과 비밀번호로 시작할 수 있어요.
- 이메일 확인 안내: 입력한 이메일로 확인 링크를 보냈어요. 링크를 눌러 계정을 활성화해 주세요.

## 이메일 확인
- 용어:
  - 사용: 이메일 확인, 이메일 소유 확인
  - 미사용: 본인인증

## 온보딩
- 출생년도 입력 설명:
  - 추천과 추세 분석 정확도를 높이기 위해 사용해요.
- 민감정보 동의 설명:
  - 초기 점검과 개인화 기능 제공을 위해 필요해요.

## 비밀번호 재설정
- 제목: 비밀번호 다시 설정하기
- 안내: 이메일로 보낸 링크에서 새 비밀번호를 설정할 수 있어요.
