# 지표/결측 정의

## 상태 대시보드

### 최근 7일 모드
- 입력: daily_state.dep/anx/ins_state_final_0_100_today
- x축: 최근 7일 날짜
- 값:
  - 해당 날짜에 상태 점수가 있으면 점/값 표시
  - 없으면 null
- 연결:
  - 기록이 있는 날짜끼리는 선으로 연결
  - 날짜 축은 그대로 유지해 결측 날짜가 보이게 함

### 최근 4주 평균 모드
- x축 버킷: 최근 4주(주 1, 주 2, 주 3, 주 4)
- 각 주 평균:
  - 그 주에 하루라도 관측이 있으면, 관측된 날의 평균으로 주평균 생성
  - 그 주 전체가 결측이면 null
- 연결:
  - 값이 있는 주끼리는 선으로 연결
  - 전체 결측 주는 비움

### 공통 표시
- metric별 그래프 3개(우울/불안/불면)
- current_score: 가장 최근 관측 또는 최신 state
- window_mean: 현재 모드의 평균
- recorded_days: 해당 창에서 값이 존재한 일수

## 활동 대시보드

### 체크인
- 이번 달 체크인한 날 수
- 최근 7일 체크인한 날 수
- 캘린더에서 checked_in=true 날짜를 표시

### CBT
- 최근 7일 세션 수
- 최근 7일 활동한 날 수
- 마지막 세션이 며칠 전인지
- (선택) 최근 주제 top 1~2

### 챌린지
- active_count: 현재 진행 중 챌린지 수
- performed_days_7d: 최근 7일 중 수행한 날 수
- completion_rate_7d: 최근 7일 수행 가능일 대비 완료율
- dropout_count_28d: 최근 28일 중도포기 건수

### 설문
- 최근 설문일
- 다음 권장 설문일까지 남은 일수
