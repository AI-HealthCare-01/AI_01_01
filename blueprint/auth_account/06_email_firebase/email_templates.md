# 이메일 템플릿/레이아웃 가이드 (Firebase 기준)

## 공통 원칙
- 짧고 명확한 트랜잭션 메일
- 마케팅 문구 금지
- 버튼 + plain link 병행
- 만료/다시 시도 안내 포함

## 이메일 확인 메일
- 제목 예: [마인드랩] 이메일 확인을 완료해 주세요
- 본문:
  - 계정 활성화를 위해 이메일 확인이 필요합니다.
  - 버튼: 이메일 확인하기
  - 보조문구: 본인이 요청하지 않았다면 무시해 주세요.

## 비밀번호 재설정 메일
- 제목 예: [마인드랩] 비밀번호 다시 설정하기
- 본문:
  - 비밀번호를 재설정하려면 아래 버튼을 눌러 주세요.
  - 버튼: 비밀번호 재설정
  - 보조문구: 본인이 요청하지 않았다면 무시해 주세요.

## 링크 복귀
- continue URL로:
  - /auth/verified
  - /auth/reset-password
  - /auth/action-expired
  같은 라우트로 유도 가능
