# 정보 구조(IA)

## 상위 메뉴
- 대시보드
  - 상태
  - 활동

## 상태 대시보드
상단:
- 모드 토글
  - 최근 7일
  - 최근 4주 평균
- 최근 설문일
- 다음 권장 설문일

중간:
- 한 화면 안의 3개 그래프(우울/불안/불면)
- 현재 점수/최근 평균 요약

하단:
- 데이터 충분도
- 마지막 업데이트 시점

## 활동 대시보드
상단:
- 한눈 요약 카드
  - 최근 7일 체크인한 날
  - 최근 7일 CBT 세션 수
  - 최근 7일 챌린지 수행일 수
  - 최근 설문일

중간:
- 월간 캘린더(체크인한 날)
- CBT 활동 요약
- 챌린지 활동 요약

하단:
- 데이터 충분도
- 다음 권장 설문일
