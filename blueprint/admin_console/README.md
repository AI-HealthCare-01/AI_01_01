# 관리자페이지 Blueprint

- 목적: 서비스 운영, 사용자 관리, 커뮤니티 모더레이션, 문의/피드백 처리, 정책 관리, 모델 운영을 한 곳에서 수행하는 관리자 콘솔
- 버전: v1
- 작성일: 2026-03-02

## 핵심 원칙
1. **3개 기본 역할**
   - Owner: 전체 권한 + 최종 승인
   - Admin: 운영/모더레이션/지원/분석 권한 묶음
   - Support: 지원 중심 권한, 필요 시 ML/Analytics 확장 권한 신청 가능
2. **승인형 변경**
   - 모든 정책 수정안과 모델 수정/배포는 **Owner 승인 후에만 적용**
3. **최소 노출**
   - 사용자 목록 기본 화면에서 IP 주소는 숨김
   - 특정 계정 차단 작업을 시작할 때만 이메일/IP를 상세 노출
4. **큐 분리**
   - 문의/피드백, 게시판 신고/유해언어, 안전/위험, 운영 경고, 모델 운영을 분리
5. **감사 로그 필수**
   - 모든 민감한 관리자 액션은 감사 로그 저장

## 폴더 구성
- `00_overview/` : 목표, 역할 구조, 메뉴 맵
- `01_product/` : 페이지 구조, UX 플로우
- `02_domain/` : 역할/권한, 상태값, 승인 워크플로우
- `03_storage/` : 테이블 스키마, 로그 스키마
- `04_backend/` : API 스니펫
- `05_frontend/` : 화면/컴포넌트
- `06_integrations/` : 게시판, 문의/피드백, 체크인/챌린지/CBT, 마이페이지 연동
- `07_security/` : PII/민감정보 접근 규칙, 차단 정책
- `08_ml_ops/` : 모델 운영 구조
- `09_implementation/` : 수용 기준, 단계별 구현
- `codex_prompts/` : Codex 시작 프롬프트
