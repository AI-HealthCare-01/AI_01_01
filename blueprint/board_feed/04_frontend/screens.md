# 화면 설계

## 1) 피드 탭
- 상단: 검색바 + 필터
- 중요 공지 핀 1개(있을 때만)
- 게시글 리스트
- 하단: '글 n개 더보기'

## 2) 공지 탭
- 공지 리스트
- 관리자 포스팅만 노출

## 3) 북마크 탭
- 북마크한 게시글만 리스트
- 피드와 같은 카드 UI 재사용

## 4) 게시글 카드
- 피드 고유번호(#P-xxxxxx)
- 제목(있으면)
- 본문 미리보기(240자 또는 8줄)
- 사진 썸네일
- 작성자명 또는 '익명'
- 작성일시
- 좋아요 / 북마크 / 댓글 수 / 신고
- '더보기'로 펼침

## 5) 작성 화면
- 제목(선택)
- 본문
- 사진 첨부
- 태그 선택
- 익명 토글
- 등록 버튼

## 6) 상태
- loading: skeleton
- empty: 첫 글 작성 유도
- search-empty: 결과 없음 + 검색어 수정 제안
