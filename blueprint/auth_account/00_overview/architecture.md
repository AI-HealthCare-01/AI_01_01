# 전체 구조

## 1. 단계별 흐름
1. 회원가입
2. 이메일 확인 메일 발송
3. 사용자가 메일 링크 클릭
4. 이메일 확인 완료
5. 첫 로그인
6. 온보딩 진입
7. 민감정보/개인화 동의
8. 프로필 기본정보 수집
   - 출생년도
   - 성별(선택)
9. 초기 진단척도 1회
10. 대시보드 / 모델 초기값 생성
11. 홈 진입

## 2. 시스템 경계
- Firebase Authentication:
  - email/password 계정 생성
  - 이메일 확인 메일
  - 비밀번호 재설정 메일
  - 이메일 액션 링크 처리
- 서비스 백엔드:
  - 내부 user_id 발급
  - 모델용 ml_subject_id 발급
  - 프로필 / 동의 / 온보딩 / 설문 저장
  - account_status / onboarding_status 관리
  - 대시보드 및 모델 초기값 계산

## 3. 핵심 분리
- 인증 시스템의 사용자 식별자: firebase_uid
- 서비스 내부 사용자 식별자: user_id
- 모델 데이터셋 식별자: ml_subject_id
