# Codex 시작 프롬프트 (활동로그)

이 레포의 `blueprint/activity_log/`를 읽고 활동로그 기능을 구현하라.

요구사항:
1) 활동로그는 마이페이지 하위 기능이다.
2) 활동로그는 day summary 조회 기능이며, 작성 기능을 포함하지 않는다.
3) 일기는 별도 기능에서 작성되고, 저장 시 활동로그에 자동 반영된다.
4) 체크인/챌린지/CBT/일기/설문을 날짜별로 요약해 보여준다.
5) 리스트와 캘린더 보기 둘 다 구현한다.
6) 일기와 CBT는 본문 전체를 리스트에 노출하지 말고 요약 미리보기만 표시한다.
7) 원천 로그와 사용자용 activity mart는 분리한다.

산출물:
- API 구현
- ETL/aggregation job
- 마이페이지 연결 화면
