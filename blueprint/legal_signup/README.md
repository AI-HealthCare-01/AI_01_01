# Legal / signup blueprint (Korea, wellness / digital health assumption)

이 폴더는 MindLab의 회원가입 / 동의 / 개인정보 처리 / 자동화된 추천 안내를
한국 기준에서 실무적으로 설계하기 위한 blueprint다.

가정:
- 제품 포지셔닝은 wellness / digital health self-management
- 의료기기 / 디지털치료기기 허가를 전제로 하지 않음
- 진단 / 치료 효과를 단정하는 copy는 피함
- 정신건강 관련 데이터는 민감정보 수준으로 보수적으로 취급
