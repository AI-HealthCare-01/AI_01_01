# Codex 작업 규칙 (문의/피드백)

- 문의/피드백은 하나의 비공개 티켓 시스템으로 구현한다.
- 내부 구분은 `ticket_type = inquiry | feedback` 로 둔다.
- 공개 게시판/피드와 혼합 금지.
- 관리자페이지 '미답변 알림 목록'은 단순 unread가 아니라 **관리자 액션이 필요한 티켓** 기준이다.
- 사용자가 추가문의를 남기면 같은 티켓이 `reopened -> waiting_admin` 으로 전환되어 관리자 큐에 다시 나타나야 한다.
- 사용자 화면에서 문의/피드백은 본인만 조회 가능.
- 완전 익명 문의는 허용하지 않는다. 사용자에게는 비공개지만 내부적으로는 계정과 연결되어야 한다.
- 제목은 필수, 본문은 필수, 첨부는 선택.
- 피드백은 `reply_requested` 옵션을 둘 수 있다.
- 알림은 상태와 분리된 별도 테이블/도메인으로 저장한다.
- 민감/긴급 신호(자해/자살/타해/위협)가 포함되면 일반 큐와 별도의 민감 큐 라벨을 붙인다.
