# 파생 지표 정의 (요약)

## 상태 추세
- 입력: `daily_state.*_state_final_0_100_today` (없으면 모델 추정치/보정치)
- 표기: 우울/불안/불면 3개 라인 차트(날짜별)

## 최근 7일/28일 변화(대시보드 스타일)
- week_delta_retro = mean(t-6..t) - mean(t-13..t-7)
- month_delta_retro = mean(t-27..t) - mean(t-55..t-28)
- 리포트에서는 '선택 기간'이므로, 기간 시작/끝에 따라 계산 가능한 구간만 표시

## 수면 규칙성
- 기상시간 규칙성 = 최근 N일 기상시각의 표준편차(분 단위)
- 평균 수면시간 = sleep_total_min 평균
- 잠들기까지 = sleep_latency_bucket 분포(15m 이하/15-30/30-60/60+)

## 생활요인
- 운동/햇빛: bucket counts 및 '10분 이상' 비율(해당 bucket 합)
- 카페인(오후2시 이후): flag 일수/비율
- 음주: bucket counts

## 관찰 밀도(신뢰도)
- 체크인 일수 / 선택 기간 일수
- 설문 횟수
- 챌린지 로그 일수
- CBT 세션 수
- 해석 문구:
  - checkin_days < 3 => '데이터가 적어 해석에 주의'
  - 3 <= checkin_days < 7 => '일부 날짜만 기록됨'
  - >= 7 => '기록이 비교적 충분'
