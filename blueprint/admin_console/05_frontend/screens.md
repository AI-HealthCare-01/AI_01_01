# 주요 화면

## 1. 운영 개요
- KPI 카드
- 큐별 건수
- 최근 7일 활동 추세
- 경고/승인 대기 섹션

## 2. 사용자 관리
- 사용자 목록(기본 IP 숨김)
- 사용자 상세 drawer/page
- 제재/차단 모달(계정 차단 / IP 차단 복수 선택)

## 3. 커뮤니티 모더레이션
- 신고 큐
- 유해언어 자동탐지 큐
- 안전 큐
- 게시글/댓글 프리뷰 + 조치 버튼

## 4. 문의/피드백
- 미답변 큐
- 전체 티켓 목록
- 상태/우선순위/카테고리 필터
- 답변, 내부 메모, 재오픈 이력

## 5. 정책 관리
- 정책 목록
- draft 편집기
- 'Owner 승인 요청' 버튼
- 적용 이력

## 6. 모델 운영
- 현재 배포 모델 카드
- 후보 실험 목록
- 성능 비교
- 재학습 요청
- Owner 승인 대기
- 배포/롤백 이력

## 7. 관리자 권한 관리
- 관리자 계정 목록
- 기본 역할 설정
- Support 확장 권한 요청/승인/회수
