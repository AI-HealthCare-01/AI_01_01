# 04. Screen Layout Rules

## 1. Home
### Structure
1. soft hero / 
2. 캘린더 출석 체크 표시
3. 진행 중 챌린지
4. 오늘의 액션 카드
   - 체크인
   - CBT 시작
   - 일기 쓰기
5. 인기 게시물 상위 3개(피드 게시판 인기글)

### Rules
- 첫 화면에서 체크인이 가장 주목되게 하기
- 적절히 절제한 배치로, 정보양 조절하여 피로하지 않게 하기

## 2. Auth / Onboarding / Form Screens
### Auth
- 중앙 정렬 카드
- 입력창 4-6개 이내
- CTA 1개 명확히

### Onboarding
- step indicator 또는 progress bar
- 민감정보 동의 -> 기본 정보 -> 초기 진단척도 순서

### Survey
- 한 화면 1문항
- 한 화면 중앙에 큰 카드, 좌우에 작은 카드 배치
- 좌우카드는 각각 이전문항, 이후문항이며 밝기와 투명도 조절하여 비활성화임을 알려주기
- 중앙 카드에는 현재 문항이 나타남
- 이전 문항으로 돌아갈 수 있는 버튼 (이후 문항은 답을 골라야만 이동 가능)
- 문항 밑에 답 선택 버튼은 가로로 한줄 정렬, 답 선택하면 다음 문항으로 이동
- 선택 버튼은 넓고 터치 친화적

## 3. Symptom Dashboard
### Header
- 기간 전환: 최근 7일 / 최근 4주 평균
- 데이터 충분도 표시

### Body
- 상단 요약 카드 3개 또는 1줄 요약
- 그 아래 한 도화지 안의 세로 3그래프
  - 우울
  - 불안
  - 불면
- 하단에 최근 설문일 / 마지막 업데이트

### Rules
- 세 지표를 하나의 선그래프에 겹치지 않음
- 4주 모드는 주평균 4점 구조

## 4. Activity Dashboard
### Body
- 최근 7일 요약 카드
- 체크인 달력
- 챌린지 / CBT / 최근 설문 카드

### Rules
- 출석률이라는 단어보다 `체크인한 날`, `기록한 날` 표현 우선
- 성과 경쟁처럼 보이지 않게

## 5. Journal
### List
- 날짜, 제목(없으면 preview), 수정 여부

### Detail
- 제목
- 날짜/시간
- 본문 전체
- 수정/삭제

### Write
- 제목 optional
- 본문 입력 영역 넓게
- 저장 CTA 명확히

## 6. Board Feed
### Header
- 검색
- 탭: 피드 / 공지 / 북마크

### Feed
- 단일 컬럼 중심
- 최신순
- `n개 더보기`

### Rules
- 완전 무한 스크롤보다 더보기 우선
- 공지는 별도 탭 + 중요 공지 1개만 상단 고정 가능

## 7. Support / Ticket
### List
- 상태 배지
- 제목
- 최근 업데이트 시간
- 재오픈 여부

### Detail
- 메시지 타임라인
- 관리자 답변
- 추가문의 버튼

## 8. My Page
### First Screen
- 프로필 요약
- 최근 활동 요약 카드
- 리포트/문의 상태 요약
- 주요 하위 메뉴 진입

### Sub Sections
- 회원정보
- 보안 설정
- 활동로그
- 북마크
- 내 글/내 댓글
- 내 문의내역
- 리포트 보관함
- 동의/개인정보 설정

## 9. Activity Log
### Position
- 마이페이지 하위 기능

### Structure
- day 기준 리스트 또는 캘린더 + 리스트
- 일기/CBT 본문 전체는 기본 노출 금지
- 원 기능 상세 링크 제공

## 10. Admin Console
### Sections
- 운영 개요
- 사용자 관리
- 모더레이션 큐
- 문의/피드백 큐
- 정책 관리
- 모델 운영
- 감사 로그

### Rules
- 큐 상태와 우선순위가 한눈에 보여야 함
- 위험/민감 항목은 색상 + 텍스트 배지 병행
