# 화면/컴포넌트 설계

## 1) 시작 화면
- 섹션 3개 소개(부드러운 이름)
- 소요 시간 안내(예: 3~5분)
- 안내: '진단 대체 아님', '최근 2주 기준'
- 버튼: 시작 / 나중에(스킵)

## 2) 문항 화면(공통)
- 진행률(예: 4/23)
- 질문 텍스트(공식 문항; 앱 내에 포함 시 라이선스/번역 검토 필요)
- 응답 버튼:
  - PHQ-9/GAD-7 공통(0~3): 0 전혀 없음 / 1 며칠 / 2 절반 이상 / 3 거의 매일
  - ISI(0~4): 문항별 anchor(공식 기준). 구현은 item_code별 옵션 목록을 로딩
- 이전/다음(다음은 선택 완료 후 활성)

## 3) 완료 화면(요약)
- 3개 카드: PHQ-9 / GAD-7 / ISI 점수 + 구간 + 검사일
- 버튼: 상세 보기 / 홈으로

## 4) 상세 화면
- 각 도구별:
  - 게이지/막대(총점)
  - 추세 그래프(최근 N회)
  - 사실 기반 설명문
- '요약 리포트에 포함' 토글(기본 ON)

## 5) 안전 안내(조건부)
- PHQ-9 위험 문항 반응(0이 아님) 시:
  - '지금 도움이 필요하면' 안내
  - 109, 119/112 등 안내(로컬 정책)
