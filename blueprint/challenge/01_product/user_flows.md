# User flows

## Browse
홈 또는 challenge 탭에서 카탈로그 탐색 -> challenge 상세 -> 시작

## Recommendation
홈/대시보드에서 추천 카드 노출 -> 이유 보기 -> 수락 또는 닫기

## Activation
지속형 challenge는 활성 슬롯 확인 -> 활성화 -> day log 생성

## Completion
사용자는 당일 수행 체크와 도움점수 입력 -> 완료 / 미완료 / 중도포기 기록

## Dropout
지속형 challenge는 사용자가 중도포기 가능
- 종료 이유는 선택형 코드로 남긴다.
