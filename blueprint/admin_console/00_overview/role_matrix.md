# 역할 구조(최종)

## 기본 역할
### Owner
- 전체 권한
- 관리자 권한 부여/회수
- 정책 변경 승인
- 모델 변경/배포/롤백 승인
- 차단 정책 최종 승인
- 민감정보 열람 가능

### Admin
- Support 권한 포함
- 커뮤니티 모더레이션
- 사용자 관리
- 차단 실행
- 정책 초안 수정
- 모델/데이터 품질 모니터링
- 재학습 job 요청/실행 가능(환경에 따라)
- **단, 최종 배포/적용은 Owner 승인 필요**

### Support
- 문의/피드백 처리
- 기본 사용자 조회
- 상태/이력 확인
- 제한적 운영 알림 확인
- 기본적으로 차단 실행, IP 상세 열람, 정책 수정, 모델 배포는 불가

## 선택 권한(지원용)
### analyst_ml_extension
- Support에게 추가 부여 가능한 확장 권한
- 범위 예시:
  - 운영 통계 상세 조회
  - 모델 성능 대시보드 조회
  - 재학습 요청 생성
  - 오프라인 평가 결과 조회
- 기본값: OFF
- 부여 방식: 신청 -> 검토 -> 승인
- 적용 후에도 **실제 배포는 Owner 승인 필요**
