# 사용자 플로우

## A. 새 문의 작성
- 진입: '문의하기'
- 폼 입력:
  - 제목(필수)
  - 내용(필수)
  - 유형(문의/피드백)
  - 카테고리(필수)
  - 관련 기능(선택)
  - 첨부파일(선택)
  - 피드백인 경우 답변 필요 여부(reply_requested)
- 제출
- 결과:
  - 티켓 생성
  - 사용자에게 '접수 완료' 상태 표시
  - 관리자 큐에 알림 생성

## B. 내 문의/피드백 내역 보기
- 리스트:
  - 상태
  - 제목
  - 유형
  - 마지막 업데이트
- 상세:
  - 사용자/관리자 메시지 스레드
  - 첨부
  - 상태 변화
  - '추가문의' 버튼(조건부)

## C. 관리자 답변 확인
- 사용자 마이페이지 알림
- 티켓 상세 진입
- 선택:
  - 해결됨
  - 추가문의

## D. 추가문의
- 기존 티켓 상세에서만 가능
- 새 메시지를 동일 티켓에 추가
- 상태: reopened -> waiting_admin
- 관리자 큐에 재등록
