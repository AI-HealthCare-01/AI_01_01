# 주요 결정사항

## 왜 가입 단계에서 성별/출생년도를 받지 않나?
- 계정 생성 자체에는 필수 정보가 아니다.
- 가입 폼이 길어지면 이탈이 커진다.
- 정신건강 관련 민감한 인상을 초기부터 주지 않기 위함이다.

## 왜 출생년도만 받나?
- 시간이 지나도 나이 파생값을 갱신할 수 있다.
- 생월/생일보다 개인정보 수집 범위를 줄일 수 있다.
- 연령대보다 모델링에서 활용도가 높고, 현재 나이보다 유지 관리가 쉽다.

## 왜 Firebase UID를 그대로 안 쓰나?
- 서비스 내부 규칙과 운영/익명화/모델링 규칙을 분리하기 위함이다.
- Firebase 교체 가능성, 데이터 export, 관리자 조회 규칙 분리에 유리하다.
