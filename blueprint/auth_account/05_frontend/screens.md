# 프론트 화면 구조

## 1. 회원가입
입력:
- 닉네임
- 이메일
- 비밀번호
- 비밀번호 확인
- 필수 동의 체크박스

행동:
- Firebase 계정 생성
- 서비스 백엔드 signup bootstrap
- 이메일 확인 메일 발송 안내

## 2. 이메일 확인 대기 화면
- 상태 설명
- '다시 보내기' 버튼
- 이메일 변경하기
- 로그인으로 이동

## 3. 로그인
- 이메일
- 비밀번호
- 이메일 미확인 시 안내
- 비밀번호 찾기 링크

## 4. 비밀번호 재설정 요청
- 이메일 입력
- 메일 발송 성공/실패 안내

## 5. 온보딩
- 민감정보/개인화 동의
- 출생년도
- 성별(선택)
- 초기 진단척도 이동

## 6. 첫 진입 로딩 게이트
- 로그인 후 account_status / onboarding_status 확인
- active_onboarding_required => 온보딩 이동
- active => 홈 진입
