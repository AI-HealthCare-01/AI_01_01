# Acceptance Criteria

## 피드
- [ ] 최신순 피드가 동작한다
- [ ] 첫 15-20개 노출 + 더보기 버튼으로 추가 로딩된다
- [ ] 피드 고유번호가 카드에 표시되고 검색 가능하다
- [ ] 제목 없는 글도 정상 노출된다
- [ ] 본문 미리보기는 240자 또는 8줄 후 더보기로 확장된다

## 탭
- [ ] 피드 / 공지 / 북마크 탭이 분리된다
- [ ] 중요 공지 1개만 메인 피드 상단 핀 가능하다
- [ ] 북마크 탭에서 저장한 글만 볼 수 있다

## 작성/상호작용
- [ ] 제목(선택), 본문(필수), 사진(선택), 익명 토글이 동작한다
- [ ] 좋아요/북마크/댓글/신고가 동작한다

## 모더레이션
- [ ] 신고 시 관리자 큐가 생성된다
- [ ] 유해언어 탐지 결과가 moderation_queue 또는 safety_queue로 분기된다
- [ ] 관리자 내부에서는 익명 글의 원 작성자를 확인할 수 있다
