# 활동로그 Blueprint

목적:
- 체크인, 챌린지, CBT, 일기, 설문 수행 여부를 **day 기준으로 모아보는 회고/확인 기능**을 설계한다.
- 활동로그는 **마이페이지 하위 기능**으로 두고, 사용자에게는 하루 단위 요약을 보여준다.
- 모델링에는 활동로그 자체가 아니라 원천 로그(raw tables)를 사용하며, 활동로그는 사용자용 파생 뷰/ETL 결과로 본다.

핵심 원칙:
- 활동로그는 **쓰기 기능이 아니라 보기/회고 기능**이다.
- 사용자는 활동로그에서 원본 항목을 요약으로 보고, 필요할 때 상세 화면으로 이동한다.
- 자유일기는 상위 메뉴인 `일기`에서 작성하고, 저장되면 해당 날짜 활동로그에 자동 반영된다.

권장 구조:

- 캘린더 보기

- 각 날짜 카드/행에서 활동 요약 + 원본 상세 화면 링크 제공
