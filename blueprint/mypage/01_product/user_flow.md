# 사용자 플로우

## 진입
- 하단 탭 또는 메뉴에서 마이페이지 진입

## 첫 화면
- 프로필 요약
- 최근 활동 요약(최근 7일 기준)
- 내 문의 상태 요약
- 최근 리포트
- 바로가기 목록

## 하위 플로우
1. 프로필 수정 -> 저장
2. 보안 설정 -> 비밀번호 변경 / 계정 탈퇴
3. 활동로그 -> 날짜/필터로 회고
4. 북마크 -> 피드 상세 이동
5. 내 글/내 댓글 -> 커뮤니티 상세 이동
6. 내 문의 -> 티켓 상세 이동
7. 리포트 보관함 -> 다운로드/재보기/새 리포트 만들기
8. 동의 및 개인정보 설정 -> 현재 동의 상태 확인/변경 가능한 항목 수정
