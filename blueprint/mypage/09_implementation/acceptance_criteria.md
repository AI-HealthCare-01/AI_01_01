# Acceptance Criteria

- [ ] 마이페이지 첫 화면에서 프로필 요약, 최근 활동 요약, 문의 상태, 최근 리포트, 빠른 진입을 확인 가능
- [ ] 회원정보 수정과 보안 설정이 분리되어 있음
- [ ] 비밀번호 변경 시에만 현재 비밀번호 입력 필수
- [ ] 활동로그가 마이페이지 하위에서 열림
- [ ] 북마크/내 글/내 댓글/내 문의/리포트 보관함으로 각각 이동 가능
- [ ] 동의 및 개인정보 설정에서 현재 사용 중인 동의 상태 확인 가능
- [ ] 마케팅 동의는 placeholder만 존재하고 실제 기능과 연결되지 않음
- [ ] 민감 액션은 audit log가 남음
