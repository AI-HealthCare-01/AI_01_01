# Acceptance Criteria

## 기능
- [ ] 기간(7/28/커스텀) 선택 가능
- [ ] 미리보기에서 8개 섹션이 규격대로 렌더됨
- [ ] PDF/PNG 내보내기 가능
- [ ] 사용자 이름/닉네임이 리포트에 포함되지 않음
- [ ] 설문이 기간 내 없으면 '최근 설문 + 경과일'로 대체 표시
- [ ] 체크인/로그가 적으면 '관찰 밀도' 배너가 뜸
- [ ] 위험 플래그는 include_sensitive=false면 숨김

## 데이터
- [ ] data_contracts.json 스키마를 만족하는 JSON 생성
- [ ] 결측(체크인 없음/설문 없음)에서도 에러 없이 동작

## 보안
- [ ] report endpoints는 인증 필요
- [ ] export URL은 만료가 있거나 스트리밍
