# Scope Boundaries

## Included in v1
- daily check-in prompt
- today's record create/update
- core question set
- local-date logic
- analytics events
- derived-feature generation spec

## Not included in v1
- journaling
- CBT thought logging
- challenge completion logging
- outing field
- social sharing
- diagnosis scales as daily questions
- free-text symptom descriptions

## May be phase 2
- night awakenings question
- nap duration
- medication adherence
- separate stress and anxiety items
- wearable data prefill
