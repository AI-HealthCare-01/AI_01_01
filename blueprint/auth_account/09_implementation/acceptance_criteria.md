# Acceptance Criteria

## 회원가입/로그인
- [ ] 이메일/비밀번호 회원가입 가능
- [ ] 이메일 확인 전 로그인 시 안내가 뜬다
- [ ] 이메일 확인 완료 후 첫 로그인 시 온보딩으로 이동한다
- [ ] 비밀번호 재설정 메일 발송이 가능하다

## 온보딩
- [ ] 출생년도 입력 가능
- [ ] 성별은 선택 입력이다
- [ ] 민감정보 동의를 받지 않으면 초기 진단척도로 진행할 수 없다
- [ ] 초기 진단척도 완료 후 account_status가 active가 된다

## 저장/ID
- [ ] user_id / firebase_uid / ml_subject_id가 분리 저장된다
- [ ] real user의 ml_subject_id는 synthetic와 구분 가능한 prefix를 가진다

## 보안
- [ ] 이메일 확인/재설정 재전송 제한이 있다
- [ ] 이메일 변경/비밀번호 변경은 최근 재인증을 요구한다
