# UX 플로우

## 진입
- 메뉴: '리포트' 또는 '진료용 요약'
- 기본 기간: 최근 28일
- 기간 선택: 7일 / 28일 / 사용자 지정(달력)

## 화면 구성
1) 상단: 기간 선택 + '미리보기'
2) 본문: 리포트 미리보기(페이지 단위)
3) 하단: '내보내기' 버튼

## 내보내기
- 포맷 선택 모달:
  - PDF (A4, 2~4p 권장)
  - 이미지(PNG, 긴 세로 1~2장)
- '민감정보 포함' 옵션(기본 ON, 단 위험 플래그는 조건부)
- 다운로드 완료 후 안내

## Empty/Warning 상태
- 기간 내 체크인이 너무 적음(예: <3일) -> '관찰 밀도 낮음' 강조 + 그래프 점선/빈구간
- 설문 없음 -> '마지막 설문 + 경과일' 표시 또는 '설문 미실시' 안내
