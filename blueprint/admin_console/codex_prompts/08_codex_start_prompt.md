# Codex 시작 프롬프트 (관리자페이지)

이 레포에는 `blueprint/admin_console/`가 있다. 이 구조를 기준으로 관리자 콘솔을 구현하라.

필수 조건:
1. 기본 역할은 Owner / Admin / Support 3개다.
2. Support는 필요 시 `analyst_ml_extension` 권한을 신청할 수 있다.
3. Owner는 전체 접근 가능하다.
4. Admin은 Support 권한 범위를 포함하며, 운영/모더레이션/모델 모니터링 접근 가능하다.
5. 모든 정책 수정 및 모델 변경/배포는 Owner 승인 후에만 반영된다.
6. 사용자 목록에서는 IP를 보여주지 않는다.
7. 특정 계정을 제재하려고 선택할 때만 이메일과 IP를 상세 노출한다.
8. 차단 UI는 `계정 차단`, `IP 차단`을 분리한 복수 선택 방식으로 구현한다.
9. 문의/피드백, 게시판 신고/유해언어, 안전 큐, 운영 경고, 모델 큐를 분리한다.
10. 모든 민감 액션은 audit_log에 기록한다.

우선 구현 범위:
- 운영 개요
- 사용자 관리(목록/상세/제재 모달)
- 문의/피드백 큐
- 커뮤니티 모더레이션 큐
- 정책 변경 승인 흐름
- 모델 운영 승인 흐름
- 관리자 권한/확장 권한 요청 처리

API와 DB 스키마는 blueprint 안 문서를 우선 기준으로 한다.
