# 사용자 플로우

## 진입
- 마이페이지 > 활동로그

## 기본 보기
- 최근 기록이 있는 날짜부터 역순 정렬
- 날짜별 카드 또는 행
- 각 날짜에 다음을 요약 표시:
  - 체크인 작성 여부
  - 챌린지 수행 개수
  - CBT 세션 수
  - 일기 작성 여부/개수
  - 설문 수행 여부

## 필터
- 전체
- 체크인
- 챌린지
- CBT
- 일기
- 설문

## 보기 모드
- 리스트 보기: 기본
- 캘린더 보기: 월 단위

## 상세 이동
- 체크인 항목 클릭 -> 체크인 상세
- 챌린지 항목 클릭 -> 챌린지 상세
- CBT 항목 클릭 -> CBT 세션 요약 상세
- 일기 항목 클릭 -> 일기 상세
- 설문 항목 클릭 -> 설문 결과 상세
