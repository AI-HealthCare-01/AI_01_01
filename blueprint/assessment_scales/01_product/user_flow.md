# 사용자 플로우

## 진입
- 마이페이지 > '상태 점검(4주)' 또는 리마인드(28일 권장)
- 수동 시작 가능(권장 주기와 무관)

## 수행
- 섹션별 분리 + 진행률
- 문항: 한 화면 1문항(모바일) 또는 2문항(태블릿/데스크톱 옵션)
- 응답: 버튼 선택(점수 + 설명). PHQ-9/GAD-7은 공통 0~3, ISI는 0~4(문항별 anchor는 별도)

## 완료
- 1) 결과 요약(3개 카드)
- 2) 상세 보기(각 도구별 게이지 + 추세 그래프 + 사실 기반 설명)
- 3) 저장 완료 안내 + (선택) '요약 리포트에 포함' 토글(기본 ON)

## 중단/재개
- 중단 시: draft로 저장(미완료 상태), 총점 계산/저장은 완료 시점에만
