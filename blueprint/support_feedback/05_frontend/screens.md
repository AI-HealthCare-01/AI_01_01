# 사용자 화면 설계

## 1) 새 문의/피드백 작성 화면
- 탭 또는 segmented control:
  - 문의
  - 피드백
- 입력:
  - 제목(필수)
  - 카테고리(필수)
  - 관련 기능(선택)
  - 내용(필수)
  - 첨부(선택)
  - 피드백일 때: '답변을 받고 싶어요' 토글
- 제출 버튼

## 2) 내 문의/피드백 목록
- 상태 배지
- 제목
- 유형
- 마지막 업데이트일
- 필터:
  - 전체 / 답변대기 / 답변도착 / 해결됨

## 3) 티켓 상세
- 메시지 스레드(채팅형 또는 타임라인형)
- 첨부 미리보기
- 관리자 답변이 있으면:
  - 해결됨
  - 추가문의
- 내부 메모는 표시하지 않음

## 4) 알림 연동(마이페이지용)
- 이 blueprint에서는 마이페이지를 설계하지 않지만, 아래 이벤트를 표시 대상으로 가정:
  - 관리자 답변 도착
  - 상태 변경
  - 추가 확인 요청
