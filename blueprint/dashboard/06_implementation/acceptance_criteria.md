# Acceptance Criteria

## 상태 대시보드
- [ ] 최근 7일/최근 4주 평균 모드가 있다
- [ ] 우울/불안/불면이 각각 별도 그래프로 표시된다
- [ ] 세 그래프는 한 화면/한 canvas 안에 함께 있다
- [ ] 7일 모드에서 기록 없는 날짜는 비우고, 기록 있는 날짜끼리는 연결된다
- [ ] 4주 평균 모드에서 주 전체 결측이 아니면 주평균이 생성된다
- [ ] 최근 설문일과 다음 권장 설문일이 표시된다
- [ ] 데이터 충분도 배너가 동작한다

## 활동 대시보드
- [ ] '출석률' 대신 '체크인한 날' 표현을 사용한다
- [ ] 월간 캘린더에 체크인한 날이 표시된다
- [ ] 최근 7일 CBT 세션 수와 마지막 활동일이 표시된다
- [ ] 진행 중 챌린지 수, 최근 7일 수행일 수, 완료율이 표시된다
- [ ] 게임형 요소(랭킹/배지/포인트)가 없다
