# 리포트 섹션(최종)

## 0. 공통 헤더
- 선택 기간 (YYYY-MM-DD ~ YYYY-MM-DD)
- 생성 일시
- 안내문: '진단/치료를 대체하지 않는 참고자료'

## 1. 핵심 요약 카드(1페이지 상단)
- 최근 상태 요약: 우울/불안/불면 (현재 수준 + 추세 한 줄)
- 최근 설문(있으면) + 날짜 / 없으면 마지막 설문 + 경과일
- 생활요인 요약: 수면/운동/햇빛/카페인(오후2시)/음주
- 위험 플래그 요약(기간 내 최고 수준만)

## 2. 증상 추세(대시보드 형태)
- 우울/불안/불면 3개 그래프(스몰 멀티플)
- 설문 시행일 마커
- 결측 구간은 점선/빈 공간 처리

## 3. 수면/생활 리듬 요약
- 평균 수면시간
- 기상시간 규칙성(최근 7/28일 표준편차)
- 잠들기까지 시간(버킷 평균/분포)
- 운동/햇빛/음주/카페인(오후2시 이후) 빈도(최근 7/28일)

## 4. 진단척도 요약
- PHQ-9 / GAD-7 / ISI: 최근 점수 + 날짜 + 경과일
- 가능하면 최근 2회 변화(델타)

## 5. 챌린지 수행 요약
- 기간 내 노출/수락/활성/완료/중도포기 요약
- 도메인별(수면/활동/조절/사회/웰빙) 집계
- 사용자 도움점수 평균(있으면)

## 6. CBT 요약(구조화)
- 세션 수
- 주제 Top N(예: 수면/불안/업무/대인)
- 사용한 기술(증거검토/행동계획/이완 등) 빈도
- 실천/숙제 시도(있으면)
- 주관적 도움 정도(있으면)

## 7. 위험/안전 요약(조건부 강조)
- 기능저하/자해/자살/타해 위험
- 날짜/출처(사용자 보고/구조화 질문) 표시
- '자동추정'이 포함될 경우 별도 표기(기본 OFF)

## 8. 관찰 밀도(데이터 신뢰도)
- 선택 기간 중 체크인 일수
- 챌린지 로그 일수
- CBT 세션 수
- 설문 유무
- '데이터가 적어 해석에 주의' 문구
