# Codex 작업 규칙 (대시보드)

- 이 폴더는 `blueprint/dashboard/` 기준 설계다.
- 구현 시 반드시 아래를 따른다.

## 상태 대시보드
- 2개 모드:
  1) 최근 7일
  2) 최근 4주 평균
- 우울/불안/불면은 각각 **별도 그래프**다.
- 하지만 세 그래프는 **한 화면, 한 캔버스(도화지)** 안에 함께 있어야 한다.
- 박스/카드로 쪼개지 말고, 하나의 시각 영역 안에서 세로로 정렬한다.
- 세 그래프는 공통 x축 개념을 유지한다.
- y축은 가능하면 0-100 공통 범위로 맞춘다.

## 결측 규칙
- 최근 7일:
  - 날짜 축은 유지
  - 값이 없는 날은 점/값을 찍지 않음
  - 관측값이 있는 날끼리는 선을 연결
- 최근 4주 평균:
  - 각 주에 하루라도 데이터가 있으면 주평균 생성
  - 주 전체 결측이면 빈 값
  - 값이 있는 주끼리는 연결

## 활동 대시보드
- '출석률' 표현은 사용하지 않는다.
- 대신 '체크인한 날', '이번 달 기록한 날'을 사용한다.
- CBT는 최근 7일 세션 수 + 마지막 활동일을 보여준다.
- 챌린지는 진행 중 개수 + 최근 7일 수행일 수 + 완료율을 보여준다.
- 퍼센트 출석률, 뱃지, 랭킹, 포인트 등 게임화 요소는 제외한다.

## 공통
- 최근 설문일과 다음 권장 설문일을 표시한다.
- 데이터가 적으면 '데이터 충분도' 또는 '관찰 밀도' 배너를 띄운다.
- 모든 API는 인증 필요. 본인 데이터만 조회 가능.
