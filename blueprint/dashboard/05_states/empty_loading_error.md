# 상태 처리

## loading
- 상태 대시보드: 그래프 skeleton 3개
- 활동 대시보드: 카드/캘린더 skeleton

## empty
- 최근 7일에 기록 없음:
  - '최근 7일에 기록된 데이터가 없어요'
  - 체크인 또는 상태 점검 유도
- 최근 4주 전체 결측:
  - '기록이 아직 부족해요. 조금 더 쌓이면 변화를 볼 수 있어요'

## warning / low density
- 최근 7일 기록 0~2일:
  - '기록이 적어 변화 해석에 주의가 필요해요'
- 최근 28일 기록 3일 미만:
  - '최근 4주 기록이 적어 주평균 추세가 불안정할 수 있어요'

## error
- 재시도 버튼
- '잠시 후 다시 시도해 주세요'
