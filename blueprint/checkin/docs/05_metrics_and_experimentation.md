# Metrics and Experimentation

## Primary product metrics
- prompt-to-submit rate
- median completion time
- skip rate
- same-day edit rate
- day-7 repeated check-in rate

## Secondary metrics
- completion rate by question
- abandonment step
- reminder conversion rate
- daily active users with completed check-in
- share of records usable for model input

## Quality metrics
- invalid payload rate
- timezone/day-boundary errors
- duplicate record conflicts

## Experiment ideas
- one-screen vs two-step flow
- 5-point control vs emoji faces for mood
- default prompt timing
- habit screen compact vs expanded
