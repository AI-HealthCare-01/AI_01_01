# 06. Reference Mapping

파일명 기준으로 레퍼런스 이미지가 어떤 화면/용도에 영향을 줬는지 요약한다.

## 1. Landing
### strong reference
- `landing2.jpg`
- `landing3.jpg`

## 2. Home / Main
### strong reference
- `dashboard9.jpg`
- `mypage.jpg`

### take from these
- hero 배경의 soft gradient
- 카드 간격
- 부드러운 CTA 구조
- 적절한 글래스모피즘 포인트

## 3. Dashboard
### strong reference
- `dashboard7.jpg`
- `dashboard9.jpg`

### take from these
- 통계 카드 + 그래프 배치
- 정보 밀도 조절
- pastel accent

## 4. Board / Feed
### strong reference
- `board-feed.jpg`
- `board-feed2.jpg`
- `board-feed3.jpg`

### take from these
- 피드 카드 폭과 텍스트 계층
- 상단 탭/검색 배치
- 액션 바 정렬 방식

## 5. Form / Survey / Auth
### strong reference
- `sign-up.jpg`
- `sign-in.jpg`
- `sign-in2.png`

### take from these
- 진단척도검사(survey)는 `assessment_layout.png` 레이아웃
- 넓은 입력창
- 선택 버튼 구조

## 5. My Page / Settings
### strong reference
- `mypage.jpg`
- `mypage2.jpg`

### take from these
- 프로필 카드 + 기능 진입 목록 구조
- 설정형 리스트 리듬
- 글래스모피즘 포인트
- 파스텔 색상 그라데이션

## 6. Admin
### strong reference
- `manage-dashboard.jpg`
- `mypage.jpg`
- `mypage2.jpg`

### take from these
- 정보 블록 나누는 방식
- 운영 화면 구성

### do not take directly
- 너무 진한 콘솔 톤
- B2B 템플릿 같은 빽빽한 화면
