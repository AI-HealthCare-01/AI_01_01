# Codex 시작 프롬프트 (일기)

이 레포의 `blueprint/journal/`를 읽고 일기 기능을 구현하라.

요구사항:
1) 상위 메뉴 `일기`를 구현한다.
2) 일기 작성/목록/상세/수정/삭제를 지원한다.
3) 제목은 선택, 본문은 필수다.
4) 목록에서는 제목 또는 preview_text만 보여주고 전체 본문은 상세에서만 보여준다.
5) 저장/수정/삭제 시 활동로그 ETL 또는 재집계를 트리거한다.
6) 홈 첫 화면에서 `일기 쓰기` CTA로 진입 가능하게 한다.

산출물:
- CRUD API
- 일기 화면
- 활동로그 연동
