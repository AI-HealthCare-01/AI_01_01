# 결정사항 요약

## 피드 구조
- 최신순 피드
- 첫 15-20개 노출 후 'n개 더보기'
- 페이지 번호 기본값 미사용
- 완전 자동 무한스크롤 미사용

## 탭 구조
- 피드
- 공지
- 북마크

## 게시글 작성
- 제목: 선택, 최대 60자
- 본문: 필수, 최대 1,500자
- 사진: 선택, 최대 4장
- 작성자 공개/익명 선택 가능(운영자 내부 식별 가능)

## 피드 표시
- 피드 고유번호 표시(예: #P-120384)
- 제목이 없으면 본문 첫 줄 일부를 내부 display_title로 사용 가능
- 피드에서는 본문 240자 또는 8줄까지 노출 후 '더보기'

## 검색
- 검색 대상: 피드 고유번호 / 제목 / 본문 / 작성자 / 태그
- 자동완성: 고유번호, 작성자, 인기 태그, 최근 검색어(선택)

## 상호작용
- 좋아요 / 북마크 / 댓글 / 신고 유지

## 모더레이션
- 신고 큐
- 유해언어 탐지 큐
- 자해/자살/타해 관련 안전 큐 분리
- 완전 익명 불가
