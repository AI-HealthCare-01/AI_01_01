# 화면 스펙

## 상태 대시보드
상단:
- 타이틀
- 모드 토글(최근 7일 / 최근 4주 평균)
- 최근 설문일 / 다음 권장 설문일

중앙:
- 하나의 시각 영역(canvas)
- 그 안에 우울/불안/불면 3개 그래프를 세로 배치
- 그래프 간 충분한 여백
- 공통 x축 개념 유지
- 개별 y축 라벨 또는 공통 y축(0~100) 표시

하단:
- 각 지표의 현재 점수/평균/기록일 수
- 데이터 충분도 배너
- 마지막 업데이트 시점

## 활동 대시보드
상단:
- 4개 요약 카드
  - 최근 7일 체크인한 날
  - 최근 7일 CBT 세션 수
  - 최근 7일 챌린지 수행일 수
  - 최근 설문일

중앙:
- 월간 체크인 캘린더
- CBT 활동 카드
- 챌린지 활동 카드

하단:
- 데이터 충분도
- 다음 권장 설문일
