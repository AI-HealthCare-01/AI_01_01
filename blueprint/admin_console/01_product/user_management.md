# 사용자 관리 화면

## 목록 기본 컬럼
- user_id
- 이메일
- 닉네임
- 계정 생성일
- 계정 상태
- 최근 로그인 시각
- 접속일 수
- 활동 수
- 최근 체크인일
- 최근 챌린지 활동일
- 최근 CBT 활동일
- 최근 진단척도검사일
- 신고 누적 수
- 문의/피드백 수

> IP 주소는 기본 목록에서 숨김

## 사용자 상세
- 계정 상태 요약
- 최근 활동 요약
- 설문/체크인/챌린지/CBT 최근 이력
- 티켓/신고 이력
- 제재 이력
- 관리자 메모

## 차단/제재 시작
- '제재/차단' 액션 클릭 시 상세 패널 열기
- 이 패널에서만 다음 상세 정보 노출:
  - 이메일
  - 최근 IP 목록
  - 의심 다중 계정 여부(선택)
