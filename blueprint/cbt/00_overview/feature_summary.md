# Feature summary

CBT 기능은 사용자의 생각/감정/행동 패턴을 구조화해 돕는 대화 기능이다.

서비스 내 역할:
- 사용자에게 구조화된 self-reflection 경험 제공
- automatic thought, emotion, behavior, evidence를 정리
- session summary와 risk signal을 export
- challenge / dashboard / current-state model에 보조 신호 제공

모델 연동 범위:
- session_count
- homework_commitment
- homework_completed_prev_flag
- emotion_shift
- belief_shift
- distortion_total_count
- helpfulness
- risk signal
