# 결정사항

## 1) 활동로그 위치
- 활동로그는 별도 상위 메뉴가 아니라 마이페이지 하위 기능으로 둔다.
- 이유: 성격이 '확인/회고'용이기 때문.

## 2) 리포트 위치
- 요약리포트 생성 기능의 본체는 별도 기능으로 유지.
- 마이페이지에는 '리포트 보관함'과 '새 리포트 만들기' 진입점만 둔다.

## 3) 회원정보 수정 vs 보안 설정
- 현재 비밀번호는 민감 변경(비밀번호 수정) 시에만 요구.
- 닉네임/출생년도/성별/알림 설정 등은 보안 섹션과 분리.

## 4) 마케팅 동의
- 지금은 사용하지 않음.
- 데이터 모델과 UI에는 disabled placeholder로만 유지.
