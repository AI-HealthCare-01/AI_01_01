# 커뮤니티 게시판(피드형) Blueprint

- 목적: SNS형 최신순 피드로 사용자 글을 소비/검색/저장(북마크)하고, 안전한 커뮤니티 운영을 위한 신고/모더레이션 구조를 제공한다.
- 범위:
  - 포함: 피드, 공지, 북마크, 검색, 댓글, 좋아요, 신고, 모더레이션 큐
  - 제외: 1:1 문의/피드백 기능(별도 설계)
- 작성일: 2026-03-01

## 최종 방향
- 메인 피드: **최신순**
- 로딩 방식: **첫 15-20개 + 'n개 더보기'**
- 공지: **별도 탭** + 중요 공지 1개만 메인 피드 상단 핀 고정 가능
- 문의/피드백: **본 범위에서 제외**
- 북마크: **별도 탭 제공**
- 피드 고유번호: 사용자에게 표시하고 검색 가능
- 유해언어/신고: 관리자 알림 + 모더레이션 큐

## 폴더 구성
- `00_overview/` : 결정사항, 근거, 범위
- `01_product/` : 정보구조, UX 플로우, 작성 규칙
- `02_domain/` : 데이터 계약, 검색 규칙, 피드/댓글/북마크 모델
- `03_backend/` : DB 스키마, API 계약, 정렬/페이징
- `04_frontend/` : 화면 구성, 컴포넌트, 상태
- `05_moderation/` : 신고/유해언어/관리자 알림 구조
- `06_ops/` : 운영정책, 숨김/제재/감사로그
- `07_implementation/` : 구현 순서, acceptance criteria
- `codex_prompts/` : Codex 실행용 프롬프트
