# User flows

1. Start CBT conversation
2. Check whether this is reflective support or safety-critical
3. Run extractor -> planner -> writer
4. Save session summary and risk signal
5. Show summary card / homework
6. If needed, route to challenge or dashboard surface

Note:
- challenge로 바로 강제 연결하지 않는다.
- free journal과 혼동되지 않게 entry point를 분리한다.
