# Codex 시작 프롬프트 (대시보드)

이 레포에 `blueprint/dashboard/`가 있다. 아래 대시보드 2개를 구현하라.

## 1) 상태 대시보드
요구사항:
- 모드 2개:
  - 최근 7일
  - 최근 4주 평균
- 우울/불안/불면은 각각 별도 그래프
- 하지만 3개 그래프는 **한 화면, 한 도화지(canvas)** 안에 함께 있어야 한다
- 박스/카드로 강하게 분리하지 말고, 하나의 시각 영역 안에 세로로 배치한다
- 최근 7일:
  - 기록 없는 날은 비움
  - 기록 있는 날끼리는 선으로 연결
- 최근 4주 평균:
  - 각 주에 하루라도 데이터가 있으면 주평균 생성
  - 주 전체 결측이면 비움
  - 값이 있는 주끼리는 연결
- 최근 설문일 / 다음 권장 설문일 / 데이터 충분도 표시

## 2) 활동 대시보드
요구사항:
- '출석률' 표현 금지, '체크인한 날' 또는 '기록한 날' 사용
- 월간 캘린더로 체크인한 날 표시
- 최근 7일 CBT 세션 수 + 마지막 활동일
- 진행 중 챌린지 수 + 최근 7일 수행일 수 + 완료율
- 최근 설문일 / 다음 권장 설문일 표시
- 뱃지, 랭킹, 포인트 같은 게임 요소는 제외

구현 순서:
1. dashboard API 2개 구현
2. 상태 대시보드 UI
3. 활동 대시보드 UI
4. 데이터 충분도/empty/error 상태 처리

반드시:
- blueprint/dashboard/02_domain/data_contracts.json 준수
- chart_rules.md 규칙 준수
