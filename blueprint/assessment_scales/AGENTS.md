# Codex 작업 규칙 (진단척도 검사)

- 문항/응답 기준은 검증판을 사용한다. (임의 재작성 금지)
  - 단, 섹션 제목/안내문/결과 설명/버튼 UI는 부드러운 톤으로 작성 가능.
- 사용자 이름/닉네임은 결과 화면/내보내기 문서에 넣을 수 있으나, 진료용 요약리포트 헤더에는 제외(별도 blueprint 준수).
- 저장 구조는 `periodic_assessment`(헤더) + `assessment_item_response`(문항별) + `assessment_score`(총점/밴드)로 분리한다.
- 28일 주기는 권장일 뿐 강제하지 않는다. `scheduled_for`, `completed_at`, `completion_status`를 저장한다.
- 결과 화면 문구:
  - '진단' 표현 금지.
  - '최근 2주 자기보고를 요약한 점수' 등 사실 중심 문장만.
- 위험 플로우:
  - PHQ-9의 자해/자살 관련 문항이 0이 아닌 경우, 조건부로 안전 안내(긴급 연락처/기관 안내)를 노출한다.
- 모든 엔드포인트는 인증 필요. 사용자는 본인 데이터만 조회.
