# Codex 작업 규칙 (마이페이지)

- 마이페이지는 '설정 + 개인 기록 허브'다.
- 첫 화면은 요약 카드와 빠른 진입점만 두고, 상세 기능은 하위 화면으로 분리한다.
- 회원정보 수정과 보안 설정은 반드시 분리한다.
  - 프로필 수정: 닉네임, 출생년도, 성별(선택), 이메일 표시, 인증 상태, 알림 설정
  - 보안 설정: 현재 비밀번호 + 새 비밀번호 + 새 비밀번호 확인, 탈퇴
- 활동로그는 마이페이지 하위 기능이다.
- 리포트는 생성 기능의 본체가 아니라 '리포트 보관함 + 새 리포트 만들기 진입점'으로 둔다.
- 동의 항목:
  - 현재 사용: 서비스 약관, 개인정보 수집/이용, 민감정보 처리, 개인화/모델 개선
  - 마케팅 동의: 현재 비활성 placeholder만 유지
- 민감정보/정신건강 데이터는 마이페이지 첫 화면에 과도하게 노출하지 않는다.
- 모든 endpoints는 인증 필요. 본인 데이터만 조회 가능.
- 삭제/탈퇴/이메일 변경/비밀번호 변경 등 민감 액션은 audit log를 남긴다.
