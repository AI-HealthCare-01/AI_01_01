# Codex 작업 규칙 (활동로그)

- 이 폴더는 `blueprint/activity_log/` 기준 설계다.
- 활동로그는 **마이페이지 하위 기능**으로 구현한다.
- 활동로그는 작성 기능이 아니라 **day summary 조회 기능**이다.
- 자유일기 작성 경로는 활동로그에 두지 않는다. 일기 저장 후 활동로그에 자동 반영한다.
- 리스트 기본 화면에서는 일기/CBT 본문 전체를 노출하지 않는다. 제목 또는 일부 요약만 보여주고 상세로 이동시킨다.
- 사용자용 활동로그(`user_day_activity_log`)와 모델링용 원천 로그(raw tables)는 분리한다.
- 활동로그는 결측일을 사용자에게 숨기지 않되, 리스트 기본 화면은 기록이 있는 날짜 중심으로 보여준다.
