# 결정사항(요약)

## 왜 문항을 '친근하게 재작성'하지 않나?
- PHQ-9/GAD-7/ISI는 검증된 도구로, 문항과 응답척도가 동일할 때만 점수 해석(구간/추세 비교)의 타당성이 유지됨.
- 문항 재작성은 별도의 자체 설문(프로프라이어터리 체크)로 분리해야 함.
- 본 설계는 '표준 도구 유지 + UI/카피만 부드럽게' 전략을 채택.

## 섹션 이름(질환명 회피)
- '우울/불안/불면'을 전면에 내지 않고, 사용자가 부담 없이 수행하도록 섹션명을 부드럽게 설정.
- 단, 투명성을 위해 작은 글씨로 도구명(PHQ-9/GAD-7/ISI)을 표기.
