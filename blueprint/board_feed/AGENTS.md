# Codex 작업 규칙 (커뮤니티 게시판)

- 이 폴더는 `blueprint/board_feed/` 기준 설계다.
- 구현 원칙:
  1) 기본 피드는 최신순 + 더보기 버튼 방식. 완전 무한스크롤 금지.
  2) 공지는 별도 탭으로 분리하되, 중요 공지 1개만 메인 피드 상단 핀 고정 가능.
  3) 문의/피드백 기능은 이번 범위에서 제외한다.
  4) 피드 고유번호(feed_public_id)는 사용자에게 표시하고, 검색 대상에 포함한다.
  5) 익명 작성은 대외 익명만 허용. 내부적으로는 작성자 계정과 반드시 연결 가능해야 한다.
  6) 본문 길이는 최대 1,500자, 댓글은 최대 500자, 제목은 최대 60자.
  7) 유해언어 탐지는 '감정의 힘듦'을 부정언어로 처리하지 않는다. 욕설/혐오/위협/성희롱/개인정보노출/도배/스팸 중심으로 다룬다.
  8) 고신뢰도 유해탐지는 자동 숨김 가능하되, 기본은 관리자 큐 우선이다.
- 인증/권한:
  - 모든 쓰기/수정/삭제/북마크/좋아요/댓글/신고는 로그인 필요
  - 관리자 기능은 별도 권한 필요
